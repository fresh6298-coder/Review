관리자용 — 처음 사용 전 설정 (한 번만)

제출된 내용은 Firebase Realtime Database의 consents 경로에 저장됩니다. 고객 개인정보가 포함되므로 조회는 인증된 관리자만 가능하도록 규칙을 설정해야 합니다.

  1. Firebase 콘솔 → Authentication → 시작하기 → 이메일/비밀번호 사용 설정
  2. Authentication → Users → 사용자 추가로 관리자 계정 생성
  3. Realtime Database → 규칙 탭에 아래 내용 게시
{
  "rules": {
    "feedbacks": { ".read": true, ".write": true },
    "surveys": { ".read": true, ".write": true },
    "consents": {
      ".read": "auth != null",
      "$id": {
        ".write": "!data.exists() || auth != null"
      }
    }
  }
}

위 규칙은 제출(신규 생성)은 누구나 가능하되, 조회·수정·삭제는 로그인한 관리자만 가능하게 합니다. 제출 내역은 consent-results.html에서 관리자 로그인 후 확인할 수 있습니다.
