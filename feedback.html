피드백 게시판

이름 / 페이지 / 피드백 내용을 남기면 아래 메인 목록에 모두와 공유됩니다.

📊 자료 보기 (새 창)
⚙️ 처음 사용 전 설정 방법 (한 번만)

이 페이지는 Firebase Realtime Database를 사용해서, 누가 어떤 기기/브라우저에서 제출하든 모든 내용이 한 곳(메인 목록)에 모이도록 만들어졌습니다. 아래 순서대로 한 번만 설정하면 됩니다.

  1. Firebase 콘솔에서 무료 프로젝트를 하나 만듭니다.
  2. 왼쪽 메뉴에서 Build → Realtime Database로 들어가 데이터베이스를 생성합니다 (지역은 아무 곳이나 선택 가능).
  3. Rules 탭에서 아래처럼 설정 후 게시(Publish)합니다. (개인/소규모용 간단 설정이며, 외부에 공개되는 게시판이라면 나중에 더 강화하는 것을 권장합니다.) 
    {
  "rules": {
    "feedbacks": {
      ".read": true,
      ".write": true
    }
  }
}
  4. 프로젝트 설정(⚙️) → 일반 탭 → 하단 "내 앱"에서 웹 앱을 추가하면 firebaseConfig 값이 나옵니다.
  5. 이 파일 아래쪽 <script> 안의 firebaseConfig 객체를 그 값으로 교체합니다.

설정 전까지는 상단에 "Firebase 설정이 필요합니다" 안내가 표시됩니다.
