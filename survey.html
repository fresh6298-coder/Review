⚙️ 처음 사용 전 설정 방법 (한 번만)

이 설문지는 기존 피드백 게시판과 같은 Firebase Realtime Database를 그대로 사용합니다 (같은 프로젝트, surveys라는 별도 경로에 저장). 아래 규칙만 한 번 추가해 주세요.

Firebase 콘솔 → Realtime Database → Rules 탭에서 surveys 항목을 아래처럼 추가하고 게시(Publish)합니다.

{
  "rules": {
    "feedbacks": { ".read": true, ".write": true },
    "surveys": { ".read": true, ".write": true }
  }
}
